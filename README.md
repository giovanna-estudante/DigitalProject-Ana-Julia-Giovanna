# DigitalProject

Projeto web desenvolvido para apresentar uma plataforma digital voltada à arquitetura, reunindo projetos arquitetônicos, galeria de imagens e informações de contato.

## Sobre o projeto

O **Digital Project** é uma aplicação web desenvolvida com React, criada para apresentar projetos arquitetônicos de forma visual e organizada.

A aplicação possui diferentes páginas para facilitar a navegação do usuário:

**Home** — apresentação do projeto e destaque para conteúdos arquitetônicos.
**Projetos** — listagem de projetos arquitetônicos.
**Galeria** — apresentação visual dos projetos.
**Contato** — informações de contato e localização da empresa através de um mapa interativo.

O projeto também utiliza imagens próprias armazenadas nos arquivos do projeto e um mapa interativo na página de contato.
